# T9-Skill proof — Deterministic Skill Verification Platform

> **"Don't just claim skills. Prove them."**

SkillProof is an evidence-based skill verification platform that turns static resume claims into verifiable, reproducible proof backed by observable GitHub engineering activity.

> **Crucial Architecture Principle**:  
> *"AI generates practical tasks and explanations. Verification is deterministic and based on observable technical evidence."*

## 📖 Project Overview

Traditional technical recruitment relies on static resumes where candidates list buzzwords with zero audit trails. Technical interviews often lean on arbitrary whiteboard riddles that don't reflect daily engineering work.

SkillProof bridges this gap by introducing an evidence-driven verification pipeline:
1. **Resume Claim Extraction**: Parses PDF resumes and extracts claimed skills using a deterministic skill taxonomy.
2. **GitHub Evidence Auditing**: Mines public repositories for observable artifacts: package manifests, language metrics, configuration files, test suites, and CI/CD pipelines.
3. **Deterministic Verification Engine (Phase 4)**: Assigns verification levels (`PROVEN`, `PARTIAL`, `CLAIMED_ONLY`, `NOT_VERIFIED`) based on a transparent, multi-signal evidence rubric.
4. **Interactive Evidence Graph**: Visualizes connections between skills, repositories, and technical proof.
5. **Job Matching & Gap Detection**: Compares verified skills against job requirements to identify evidence gaps.
6. **AI Micro-Task Generation**: Generates targeted, 30–60 minute tasks targeting candidate skill gaps.
7. **Re-Verification Loop**: Candidates push real code to GitHub; SkillProof re-evaluates the delta and updates status transparently.
8. **Evidence Portfolio & Print Report**: Generates an auditable, shareable portfolio with a print-optimized executive summary.

## 🚀 Key Features

- **Automated Resume Analysis**: Instant extraction of candidate technical claims with normalized skill taxonomy.
- **Deep GitHub Evidence Mining**: Evaluates real repository contents (package dependencies, unit tests, Docker configs, CI/CD workflows, language distribution).
- **Deterministic 4-Tier Verification**:
  - 🟢 **PROVEN** (Score $\ge 60$): Multi-signal proof across implementation files, manifests, and test suites.
  - 🟡 **PARTIAL** (Score $\ge 25$): Valid code/dependency detected, but missing complementary depth signals.
  - ⚪ **CLAIMED ONLY** (Score $< 25$): Listed on resume or minimal README mentions without code artifacts.
  - 🔘 **NOT VERIFIED**: No observable public evidence discovered.
- **Evidence Graph Visualization**: Interactive node graph connecting skills, repositories, and technical proof.
- **Intelligent Job Matching & Gap Engine**: Prioritizes skill deficiencies as **HIGH**, **MEDIUM**, or **LOW** without arbitrary applicant ranking.
- **Targeted AI Micro-Tasks**: Tailored, hands-on coding scenarios generated by AI with strict acceptance criteria and deliverables.
- **Automated Re-Verification**: Real-time evaluation of submitted GitHub repositories with before/after score deltas.
- **Executive Portfolio & Print Report**: Clean, shareable evidence dossier with print-optimized CSS for executive PDF export.

## 🔌 Dataset & API Information

- **GitHub REST API v3**:
  - Endpoint: `https://api.github.com`
  - Fetches repository metadata, tree hierarchies, language distributions, and raw package manifests (`package.json`, `pom.xml`, `requirements.txt`, `Dockerfile`, etc.).
  - Authenticated via optional `GITHUB_TOKEN` for 5,000 req/hr (unauthenticated rate limit: 60 req/hr).
- **Generative AI APIs**:
  - Supports Google Gemini (`@google/genai`), Groq, or OpenAI.
  - Used strictly for job spec parsing and micro-task scenario generation. AI never assigns scores.
- **Skill Taxonomy Dataset**:
  - Deterministic built-in skill taxonomy covering 100+ technologies across Frontend, Backend, DevOps, Data, and Mobile.

## 🛠️ Setup & Installation Instructions

### Prerequisites
- **Node.js**: v18.17.0 or higher
- **npm**: v9.0.0 or higher

### Installation

```bash
# Clone the repository
git clone https://github.com/veersingh-mu/Skill-proof.git
cd Skill-proof

# Install all dependencies
npm install
```

### Environment Configuration

Create a `.env.local` file by copying the example:

```bash
cp .env.example .env.local
```

Populate the keys in `.env.local`:

```ini
# Optional: GitHub Personal Access Token (increases rate limit from 60 to 5000/hr)
GITHUB_TOKEN=your_github_personal_access_token_here

# Optional: AI Provider (gemini, groq, openai)
AI_PROVIDER=gemini
AI_API_KEY=your_gemini_api_key_here
```

### Running the Application

```bash
# Run local development server
npm run dev

# Open in browser: http://localhost:3000
```

### Running Test Suite & Quality Checks

```bash
# Run Vitest test suite
npm test -- --run

# Run TypeScript type check
npx tsc --noEmit

# Run ESLint check
npm run lint

# Build production bundle
npm run build
```

## 🔒 Security Model

1. **Zero Code Execution**: Candidate code is never cloned, installed, or executed. No `npm install`, `pip install`, `docker run`, or terminal child processes.
2. **SSRF & URL Whitelisting**: Strict regular expressions validate all repository submissions to ensure only legitimate `github.com` URLs are inspected.
3. **Zero Secret Leakage**: API tokens reside purely on the server-side (`process.env`). Never exposed to client storage, bundles, or API responses.

## ⚖️ Limitations & Future Scope

### Current Limitations
- **Public Repositories Only**: Current static inspection focuses on public GitHub repositories; private enterprise codebases cannot be audited without OAuth integrations.
- **GitHub Rate Limits**: Unauthenticated scans are limited to 60 calls/hr without a personal access token.
- **Static Artifact Inspection**: Focuses on static evidence (manifests, workflows, test files, configs) rather than code coverage percentages or runtime benchmarking.

### Future Scope
- **GitLab & Bitbucket Support**: Multi-platform VCS integration for private enterprise audits.
- **Automated CI/CD Webhooks**: Automated badge updates in repository READMEs whenever new code passes verification.
- **Cryptographic Attestations**: Issuing verifiable credentials (W3C standard) for verified skill proofs.
- **Organization Workspaces**: Team and recruiter dashboards to view candidate pipelines by verified evidence.
